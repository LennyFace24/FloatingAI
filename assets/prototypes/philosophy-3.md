# 设计哲学 · 第三批（修订）：一球一义（The Orb Speaks）

## 运动宣言

上一版哲学犯了一个错误：把"简洁"误读为"删光"。删到只剩下抽象的圆与线，图标失去了身份——它不再告诉用户这是什么产品。

这一版修正：**简洁不是删去身份，而是只讲一件事。** FloatingAI 的产品身份由一个核心形态承载——**悬浮球**：一个常驻桌面边缘、随时可以呼出的圆形助手。它是产品最独特、最可识别的物理存在，是用户每天看着的那颗球。

因此第三批的全部原型共享一个铁律：**悬浮球必须是绝对主体**，占据画面核心、拥有最重的视觉权重。图标的任务不是抽象地"好看"，而是让任何人一眼认出：这是一颗悬浮的 AI 球，常驻你的桌面边缘，随时准备对话。

## 一球一义

每个原型只附加**一个**产品语义，且必须与产品真实功能对应：

- **K · 悬浮 F 球** — 品牌字母 F 住在球里。球 = 产品形态，F = 品牌身份，一图双识。
- **L · 球泡合一** — 悬浮球本身就是对话泡，带一点尾巴、三点省略。球 = 对话入口，形态即功能。
- **M · 边缘嵌入** — 球半沉入桌面边缘线。球 = 悬浮体，线 = 屏幕边缘，一图讲清"常驻桌面边缘"。
- **N · 呼出输入** — 球在上、输入条在下。球 = 触发点，条 = 结果，一图讲清核心交互"点击呼出输入"。
- **O · 呼之即答** — 球发出对话声波。球 = 助手，波纹 = 随时应答。

每张图只承担一个语义。删掉球，图就不成立——这正是产品识别的来源：**球不可缺席**。

## 色彩与材料

延续应用 tokens：近黑 `#0b0b0b` 底、深灰 `#141414` 球体、`#3a3a3a`–`#555` 描边。亮色严格克制——白色 `#e6e6e6` 用于承载语义的元素（字母、三点、声波），终端绿 `#7af08a` 只作为"在线/待命"信号出现，每张最多一处、面积最小。图标在 32px 下可辨识，在 512px 下依然精密。

## 尺度与节奏

球体直径约占画布 60%，确保主体地位；其余元素按语义层级递减。留白依然重要，但让位给可读性——识别度优先于装饰性。每根描边的粗细、每个圆角曲率都经过像素级校准，作品呈现为一位顶级设计师花费无数小时雕琢的产物：删繁就简之后，留下的每一笔都承担身份。
