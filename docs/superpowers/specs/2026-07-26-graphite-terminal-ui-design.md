# Graphite Terminal UI 设计规格

日期：2026-07-26
状态：用户已批准

## 1. 目标

将 Floating AI 的现有功能界面升级为深色黑白、shadcn 风格、纯净毛玻璃质感的桌面 AI 工具，同时完善悬浮球展开/收回动效与 Markdown、代码、LaTeX 富文本渲染。

## 2. 视觉方向

采用 Graphite Terminal · Pure Glass。

- 默认深色主题。
- 严格使用黑、白、灰，不使用蓝色、绿色、紫色或霓虹强调色。
- 不使用径向渐变、光晕、喷漆灰、背景网格、颗粒噪点或闪烁装饰。
- 毛玻璃只用于透出桌面轮廓，不额外制造背景纹理。
- 整体气质偏开发者工具，但正文不全局使用等宽字体。

## 3. 颜色与材质

固定灰阶：

- Void：`#050505`，窗口最底层。
- Glass：`rgba(8, 8, 8, 0.92)`，主窗口玻璃面板。
- Input：`#101010`，输入区。
- Inline：`#181818`，行内公式等局部表面。
- Primary text：`#f2f2f2`。
- Secondary text：`#a0a0a0`。
- Border：`rgba(255, 255, 255, 0.12)`。

层级只能通过固定透明度、细边框、内高光和克制阴影表达。

## 4. 顶部栏

顶部栏不显示品牌装饰。

移除：

- `FLOATING / AI` 文字。
- 左侧圆形图案。
- 状态圆点。

保留右侧必要操作：

- 设置：Lucide `Wrench` 图标。
- 收起：Lucide `Minus` 图标。
- 图标按钮均使用 30×30 px 视觉尺寸和至少 40×40 px 点击区域。
- 均提供 tooltip 和 `aria-label`。

## 5. 对话气泡

用户和 AI 气泡必须与主背景属于同一黑灰材质，只是深度不同。

- 用户气泡：约 8.5% 白色叠加、较明显细边框和轻阴影，右对齐，右下角切角。
- AI 气泡：约 5% 白色叠加、较弱边框，左对齐，左上角切角。
- 禁止纯白用户气泡。
- 文本颜色保持高对比度。

## 6. 输入区

输入区只允许一个输入容器。

- 输入文本和 placeholder 直接位于容器内。
- 发送按钮位于容器右侧，作为唯一独立控件。
- 禁止在真实输入框表面再覆盖灰色假输入框。
- 支持多行输入，但保持稳定高度和内部滚动。

## 7. 悬浮球与动效

采用 Anchored Morph。

- 展开：约 280ms，从悬浮球所在位置向屏幕可用方向连续生长。
- 收回：约 180ms，沿原路径返回悬浮球。
- 内容在展开进度约 35% 后淡入。
- 关闭时内容先淡出，再收缩窗口。
- 动效必须可中断，不阻塞点击。
- 遵守 `prefers-reduced-motion: reduce`，此时直接切换或使用极短淡入淡出。
- 不使用明显回弹、扫描线或装饰性闪烁。

## 8. 富文本消息

AI 消息支持：

- CommonMark Markdown。
- GFM 表格、任务列表、删除线和自动链接。
- 标题、段落、列表、引用、分隔线和链接。
- 行内代码与围栏代码块。
- LaTeX 行内公式和独立公式块。

代码块：

- 显示语言标签。
- 使用黑白灰语法高亮。
- 提供 Lucide `Copy` 按钮和复制成功反馈。
- 长行横向滚动，不撑破气泡。

公式：

- 行内公式使用 Inline 表面。
- 独立公式块居中并允许横向滚动。
- 原始 HTML 默认禁用，避免脚本注入。

## 9. 技术方案

- 图标：`lucide-react`。
- Markdown：`react-markdown`。
- GFM：`remark-gfm`。
- 公式解析：`remark-math`。
- 公式渲染：`rehype-katex` + `katex` CSS。
- 语法高亮：按需注册语言的轻量高亮组件，避免把全部语言打进主包。
- React 内容动效：CSS transform/opacity 或 Motion。
- Tauri 原生窗口尺寸变化通过 Rust 窗口管理器实现，与前端表面事件同步。

## 10. 验收标准

1. 主窗口为纯净深色黑白玻璃，无渐变、光晕、网格、颗粒或喷漆灰。
2. 顶部没有品牌文字、圆形装饰或状态点。
3. 设置按钮使用 Wrench，收起按钮使用 Minus，并有 tooltip。
4. 用户与 AI 气泡均为黑灰背景，不出现纯白用户气泡。
5. 输入区只有一个真实输入容器。
6. 悬浮球展开和收回具有连续 Anchored Morph 动效。
7. 减少动态效果设置下不播放复杂动画。
8. Markdown 标题、列表、表格、引用、链接正常显示。
9. 代码块有语言标签、高亮和复制功能。
10. 行内和块级 LaTeX 正常显示。
11. 原有发送、停止、清空、设置、收起和拖拽功能保持可用。
